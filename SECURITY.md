# Security policy

Chronotif reads your notifications locally and never sends data anywhere, so security reports
are taken seriously.

**Please report vulnerabilities privately** using GitHub's
[private vulnerability reporting](../../security/advisories/new) rather than a public issue.
Examples: notification content leaking onto the lock screen, actions that can be triggered
without unlocking, or another app being able to drive Chronotif.

You can expect an acknowledgement within a few days. Only the latest release is supported.
